# Безопасность

## Сообщение об уязвимости

Не публикуйте уязвимости в публичных issue. Используйте приватный канал:

- GitHub: Security → Report a vulnerability (Private Vulnerability Reporting) для репозитория `ivlev-dev/umbrawg`.

## Область

- UAPI-сокет `/var/run/umbrawg/<iface>.sock` (права доступа, проверка UID/GID, path traversal).
- Привилегии: запуск `uwg`/`uwg-quick`, запись конфигов и ключей.
- Парсинг конфигов (`uwg setconf`/`syncconf`): инъекции, переполнения, невалидный ввод.
- Обработка ключей и секретов (zeroize).

## Сроки ответа

- Подтверждение получения: до 72 часов.
- Оценка и план исправления: до 7 дней.
- Исправление критических уязвимостей: до 14 дней.
- Публичное раскрытие — после выхода исправления, по согласованию.
