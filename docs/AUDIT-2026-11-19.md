## Исправлено

### Критичное и высокое

- **NAT-совместимость extra ports.** Дополнительные source-порты ломали
  handshake и TCP за port-restricted NAT: проверено — ping 80% потерь,
  TCP FAIL. Дефолт `extra_ports` снижен с 4 до 0; функция остаётся
  per-device настройкой (`ExtraPorts`, `extra_ports=`,
  `UWGDEVICE_A_EXTRA_PORTS`). С 0 — ping 0%, TCP 3.3 Гбит/с.
- **UAF при удалении интерфейса.** `jp_spec_free()` больше не вызывается
  до остановки handshake/workqueue.
- **OOB-read в GSO-агрегации.** Копирование сегментов переведено на
  `skb_copy_bits()`: корректно для нелинейных skb с `frag_list`.
- **`uwg-quick` + sudo.** Запускается `current_exe()`, а не `argv0` из
  CWD; каталог бинарника добавляется в конец `PATH`, а не в начало.
- **`uwg-quick save`.** Временный файл: `O_EXCL|O_NOFOLLOW`, режим 0600.
- **`ExtraPorts` и старые демоны.** `showconf` печатает ключ только если
  устройство его реально сообщило, `setconf` не отправляет его без
  необходимости; amneziawg-go и старый Rust-демон не ломаются (проверено
  `showconf` на Go-демоне — ключа нет).
- **Неудачный rebind.** Демон продолжает обслуживать прежний сокет,
  повторяет попытку раз в секунду; при занятом `listen_port` трафик
  сохраняется (проверено: 11 ошибок bind, loss 0, 5.3 Гбит/с).
- **Транзакционность `set=1`.** Обфускация и тайминги валидируются до
  применения; ошибка не меняет ключ и не удаляет пиров (проверено).
- **`fwmark` на живом демоне.** Применяется через `SO_MARK` без
  пересоздания сокетов.
- **Таймауты UAPI.** Клиент — 10 с и 16 МиБ ответа; сервер закрывает
  простаивающее соединение через 10 с.
- **Счётчики пира в ядре.** `rx_bytes`/`tx_bytes` переведены на
  `atomic64_t` (32-битные ядра).
- **OOM-пути ядра.** `jp_spec_setup`: инициализирован `buf`;
  `consume_initiation`: endpoint на стеке; junk-буфер проверяется на NULL.
- **`-EBUSY` crypto API.** Ожидание completion только при
  `-EINPROGRESS`, без вечного ожидания.
- **Порядок публикации extra-сокетов.** `smp_store_release`/
  `smp_load_acquire`, быстрый путь без атомика при `count == 0`.
- **Netlink.** Проверка диапазона `ExtraPorts > 8`, исправлен сдвиг при
  `prefix_len == 0`, разблокировка `endpoint_lock` на error-path.

### Среднее и низкое

- `UDP_GRO` читается как 4-байтовый `int` (big-endian).
- Control-буфер 64 → 128 байт (`MSG_CTRUNC` больше не теряет GRO/sticky).
- GSO сверх лимитов сокета уходит сегментами, а не отключает GSO навсегда.
- `Keypair::seal*` переведены в `pub(crate)`/`cfg(test)` — внешний counter
  больше нельзя использовать для nonce reuse.
- В обычном режиме воркеры супервизятся; при неожиданном выходе демон
  останавливается, а не теряет четверть трафика.
- Изменение MTU TUN при работе логируется как предупреждение с
  требованием рестарта (пакеты больше не теряются молча).
- `uwg show` показывает число дополнительных портов, если оно не ноль.

## Отложено осознанно

- **Sticky source для extra ports.** Правильное решение — отвечать с
  ingress-сокета и закреплять сокет за пиром; это крупная переделка
  data-path (ядро и Rust). До неё extra ports остаются opt-in для сетей
  без NAT.
- **Транзакционность netlink SET в ядре.** Ошибка в поздних атрибутах
  (J/S/H/I/peer) оставляет ранее применённые listen-port/fwmark/extra.
  Требует двухфазного применения; доступно только root.
- **Replay-проверка до AEAD.** Требует разделения replay-фильтра на
  `check`/`commit`; сейчас цена — полный AEAD на реплей.
- **`send_split` при EAGAIN.** Возможна повторная отправка части
  GSO-супердатаграммы; нужен возврат частичного прогресса.
- **Копии в Rust RX/TX и размер `Job`.** 2–3 копии на пакет и ~2.5 КБ
  служебной структуры на датаграмму в parallel RX; вынос prepared в
  компактный вид и `readv` для TUN — отдельная оптимизация.
- **Память extra ports.** `воркеры × (N+1) × 2 × буфер`; при дефолте 0
  не проявляется. Общий `SocketSet` на все воркеры — архитектурный шаг.
- **`listen_port=0`** не публикует фактический порт в `get=1`
  (унаследованное поведение).
- **Header protection rwsem на пакет** и пул из 4 AEAD-слотов — perf-
  оптимизации без влияния на корректность.
