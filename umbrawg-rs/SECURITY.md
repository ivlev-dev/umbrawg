# Безопасность

## Сообщение об уязвимости

Не публикуйте уязвимости в публичных issue. Используйте приватный канал:

- GitHub: Security → Report a vulnerability (Private Vulnerability Reporting) для репозитория `ivlev-dev/umbrawg-rs`.

## Область

- UAPI-сокет `/var/run/umbrawg/<iface>.sock` (права доступа, проверка UID/GID, path traversal).
- Привилегии демона: создание TUN, привязка UDP-портов, запись runtime-файлов.
- Парсинг конфигов и ключей (Noise IK, обфускация 3.1).
- TUN-устройство: многопоточность, GSO/GRO, обработка пакетов.
- Криптография: ключи, nonce, replay-защита.

## Сроки ответа

- Подтверждение получения: до 72 часов.
- Оценка и план исправления: до 7 дней.
- Исправление критических уязвимостей: до 14 дней.
- Публичное раскрытие — после выхода исправления, по согласованию.
